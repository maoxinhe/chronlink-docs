常见问题

约 2883 字大约 10 分钟

2026-11-27

下面是玩家问得最多的问题，按「下载安装 → 登录 → 资源下载 → 实例导入 → 实例使用 → 其他」分类。本篇随版本更新，示例以 ChronLink 1.11.2-beta.4 为准。

这里没找到你的问题，可以看左侧故障排查四篇（Windows 安装与权限、Java 环境、启动崩溃、联机与正版验证），或直接问右下角的 AI 助手。

反馈问题时请带上：做了什么操作、期望结果、实际结果，以及实例日志（实例详情页 → 文件 → 日志）。有日志才好定位。

杀毒软件拦截安装包或启动器：火绒、360、卡巴对未签名的开源 exe 经常误报。ChronLink 源码完全公开（GitHub），可自行审查；误报请把文件加入信任，或临时关防护完成安装。

I. 下载与安装

我该下载哪个文件？

ChronLink 只发布 Windows 版本：x64（绝大多数 Intel / AMD 机器）和 arm64（骁龙 X 系列等 ARM 设备），没有 macOS、Linux、安卓、鸿蒙版本。

到 GitHub Releases 按文件名挑：

  • ChronLink_<版本>_x64_modern-setup.exe —— 普通电脑的安装版
  • ChronLink_<版本>_arm64_modern-setup.exe —— ARM 设备安装版
  • ChronLink_<版本>_x64_portable.zip / _arm64_portable.zip —— 便携版

完整步骤（含 SmartScreen、WebView2、VC++ 处理）见 安装与更新。

Edge / Chrome 提示「通常不会下载 XXX.exe」

安装包没有买代码签名证书（开源免费分发很常见），浏览器会拦一下：

  1. 下载栏右侧点「…」（更多操作）
  2. 选「保留」
  3. 弹窗里点「显示更多」→「仍然保留」

双击 exe 弹出「Windows 已保护你的电脑」

SmartScreen 的判断依据是签名和下载量，未签名的新版本必然触发：

  1. 点「更多信息」
  2. 点「仍要运行」

安装向导里点「浏览」没反应 / 选不了文件夹

系统缺 WebView2 Runtime，启动器界面和安装向导都依赖它：

  1. 装微软官方运行时：WebView2 下载页（选 Evergreen Bootstrapper）
  2. 提示需要管理员权限就右键「以管理员身份运行」
  3. 装完重启电脑，再跑安装包

提示找不到 VCRUNTIME140_1.dll / api-ms-win-crt-*.dll

缺 VC++ 运行库：

  • x64：vc_redist.x64.exe
  • arm64：vc_redist.arm64.exe

装完重新打开启动器。

官网 / GitHub 打不开，还能从哪下？

  • GitHub Releases：https://github.com/maoxinhe/ChronLink/releases/latest（一般能直连，慢就换网络或挂加速）
  • 文档站下载页：下载 里是同一批直链
  • 官网：launcher.camzy.tech

注意

别从网盘、群里转发的安装包更新——那种包没法校验来源，也没法保证是最新版。

便携版在哪下载？

在 Releases 的 Assets 里找 ChronLink_<版本>_x64_portable.zip 或 _arm64_portable.zip，解压到任意目录双击 ChronLink.exe 就能用，不写注册表，删目录即卸载。

启动器怎么更新？

启动器每次启动都会向云端上报自己的版本号，云端比对后决定是否下发更新；有新版会下载并提示重启。也可以在 设置 → 更新 里手动点「检查更新」。

支不支持 Win7 / Win8？

不支持。启动器依赖 WebView2，最低要 Windows 10 1809，推荐 Windows 11。

II. 登录账号问题

我没看到登录的选项怎么办？

请点击窗口右方的「展开边栏」按钮

为什么提示要先登录正版账号？

离线模式只影响本地单人游戏。正版验证服务器和 Realms 必须用正版账号，这是服务端校验，不是启动器限制。

启动器支持哪些登录方式？

启动器现已支持正版账号登录（需要在minecraft.net购买过Minecraft Java版），离线账号登录与第三方登录（如Littleskin）。

注意：离线登录与第三方登录无法游玩Realms与开启了正版验证的服务器。

我没办法正版登录怎么办？

多半是网络连不上微软登录服。先关掉代理 / 加速器再试，仍不行就换网络环境。

为什么我的网络是正常的，却显示为离线模式？

先关掉代理和加速器，点旁边的刷新按钮重连；账号服务在境外，网络环境不对就会显示离线。

III. 资源下载问题

下载速度太慢怎么办？

下载走的是 Modrinth / 官方 CDN，速度取决于你的网络到境外节点的质量。慢的话按顺序试：

  • 设置 → 内容与下载 → 下载行为 → 打开「强制多连接下载」

  • 用「网络测试」页选一个延迟最低的下载源（Minecraft 元数据 / Modrinth / CurseForge 可分别设置）

  • 完全下不动时，在 设置 → 网络与多人游戏 里关闭 DNS over HTTPS 再试

找不到mod下载的地方怎么办？

你需要先下载一个任意版本包含任意模组加载器的实例，之后才会在发现页面中显示模组选项。

如果你不想按照指定实例版本信息筛选模组，可在侧边栏解锁筛选（可能下错误的版本）

IV. 实例导入问题

我应该如何直接使用我已有的.minecraft文件夹？

Windows 默认位置
资源管理器里粘贴这一行
%APPDATA%\.minecraft

在创建实例时我们提供了这个选项。你也可以进入设置-存储与备份-Minecraft目录中选择你正在使用的.minecraft文件夹。

注意：是.minecraft文件夹而不是/versions文件夹！！

直接使用.minecraft文件夹与导入.minecraft文件夹有什么区别？

ChronLink是基于Modrinth app更改的。Modrinth与国内绝大多数启动器所使用的文件结构都不一样。

简单来说，Modrinth内安装了不同模组但是版本相同的实例只需要共用同一份资源文件。很多资源文件甚至所有实例都可以用。因此这是一种更加节约磁盘空间的文件存储方案。值得注意的是，其他启动器有版本隔离这一选项，而ChronLink没有，就是因为这种差异。你可以理解为，ChronLink自带版本隔离。

ChronLink在1.9.6版本提供了对国内常见的.minecraft文件结构的适配。目前你可以使用两种方式导入已有的实例。

如果使用的是我们提供的导入功能，那么启动器将会自动将原本的.minecraft文件夹转化为modrinth的格式。

如果你直接在设置里添加了.minecraft文件夹，那么启动器将会自动识别里面的所有实例，不需要额外下载任何内容。在启动器内对其中的实例进行删除等操作会直接应用到这个文件夹，如果你是多个启动器共用这个文件夹，那么在其他启动器内，这个实例也会消失。

目前我们更推荐直接使用.minecraft而不是导入。导入功能尚存在许多问题。如果你导入实例时出错，可以直接使用.minecraft文件夹。

为什么我导入实例还需要下载内容？

需要下载的内容就是不同启动器之间能够共享的文件。这样能够更好的管理游戏元文件，Java等。模组，光影等文件不会重新下载。

V.实例相关问题

为什么整合包下的模组无法单独更新？

整合包的更新由整合包发布者负责，所以你没有办法单独更新其下的某个模组。如果你想更新，可以在设置-安装内选择与整合包解除关联。

怎么给指定的实例安装整合包，模组等内容？

方法一：点进某个实例，点击“浏览内容”。

方法二：如果你要下的不是整合包：

进入发现页面，在指针处选择目标实例

选择完毕后，将会自动筛选符合该实例游戏版本与加载器版本的模组（也可以在右侧解除筛选），点击安装即可。

下载时怎么指定整合包，模组等内容的版本？

首先找到你要的模组/整合包，点击标题。

选择你需要的版本即可。

如果不选择，启动器将会根据实例加载器自动选择最新版本。

如何为实例分组？

进入实例库页面，批量选择要分组的实例。

选择编辑分组。

在分组名称内输入组名，点击创建新分组，然后选择即可。

注意

右键点一下分组标签上的「…」才能重命名 / 删除，直接双击只会切换进入该分组。

我在其他启动器和ChronLink启动器游玩同一个实例有帧数差距，如何解决？

可以在实例设置内选择Java及内存，点开自定义Java参数。会默认使用自动GC调优。

如何给我的模组加载器更新？

实例设置-安装-编辑内即可更改加载器版本。

VI. 其他使用中问题

为什么我无法使用翻译？

目前Microsoft翻译已经全部不可用，预计未来也不会再恢复了。因此我们添加了谷歌翻译优选，使其在国内也能使用。但是尽管如此，仍然也有一些用户也无法使用谷歌翻译，请谅解。

解决方法：

法一：在设置-翻译内将翻译服务更改为Google翻译。

请注意，如果切换后下方的可用旁边的数字是0，则无法使用谷歌翻译。

法二：在设置-AI中配置自己的AI（请注意，ChronLink不会提供免费api) ，将“启用AI功能”调整为开启，然后在设置-翻译内将翻译服务更改为AI模型。

太卡了/我内存占用太高了怎么办？/有没有内存优化？

注意，请区分内存与存储空间的区别！

你可以通过设置-默认实例选项里调整给实例分配的内存，也可以单独选择某一个实例-设置-Java及内存自定义内存分配。

内存优化入口在设置-Java与性能里。仅支持Windows！

新增了启动前自动优化内存的选项。若想单独为某一实例启用，需要在实例设置里勾选自定义内存分配才会显示。

我联机报错怎么办？

首先需要明确的是，联机并不是ChronLink开发的，使用的是别人提供的服务。

解决方法：

法一：更换联机方式。目前有陶瓦联机和红石联机两种选择。

如果两种方案都报错，可把报错截图 + 日志发到 GitHub Issues，附上联机方案名和报错文本。

打开启动器提示Download request failed是什么问题？

通常是更新检查时连不上云端接口。重启启动器重试；多次失败可在 设置 → 更新 里看当前的更新通道，或到 GitHub Releases 手动下最新包覆盖安装（实例数据不会动）。

提示系统i/o问题找不到指定的路径怎么办？

请检查路径中是否包含中文，如果有，请改为英文。
