# 支持与贡献

ChronLink 的进步离不开社区的支持！

## 遇到问题怎么办？

先翻一遍这份文档，特别是[常见问题](faq.md))。还解决不了？

- **GitHub Issues**：[https://github.com/maoxinhe/ChronLink/issues](https://github.com/maoxinhe/ChronLink/issues)
- 报 Bug 时附上：实例日志（实例详情 → 日志页复制）、复现步骤、你的系统（Windows / macOS / Linux）

## 想参与开发？

从玩家变成开发者，欢迎！

- 阅读 CONTRIBUTING.md 了解本地开发环境搭建与打包发布规范
- 项目是 Rust (Tauri) + Vue 的 monorepo，提 PR 前先看贡献指南

## 帮忙翻译

翻译协作在 **GitHub** 上进行：直接在[项目仓库](https://github.com/maoxinhe/ChronLink)的翻译文件（locales 目录）里翻译好，然后提交 Pull Request，我们会尽快合并。把 ChronLink 翻译成更多语言，走向全世界！

## 点个 Star

喜欢 ChronLink？去 [GitHub 仓库](https://github.com/maoxinhe/ChronLink) 点个 Star，就是对我们最大的鼓励！
