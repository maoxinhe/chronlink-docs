## 先花 30 秒弄明白：你在玩的是什么

**Minecraft（我的世界）** 是一款沙盒游戏，你可以在里面自由建造、冒险、生存。

Minecraft 有两大版本：

- **基岩版**：手机上、主机上、Win10 商店里那个，跨平台联机方便
- **Java 版**：电脑上最经典的版本，能装模组、玩各种花活，**这是我们今天的主角**

Java 版不能直接玩，需要一个叫“启动器”的东西来打开它。**ChronLink（ChronLink 启动器）** 就是这样一个启动器——而且可能是你的最后一个。

## 用 ChronLink 能干嘛？

- **一键开玩**：选个版本，点启动，游戏就跑起来了，Java 都不用你自己装
- **装模组、装整合包**：想让游戏更好玩？内置的内容中心一键搞定，不用去网上东翻西找
- **管理多个游戏环境**：一个生存档、一个模组档、一个开黑档，互不干扰
- **全平台免费**：Windows、macOS、Linux 都能用，开源无广告
