# 快速上手

装好 ChronLink 之后，跟着这三篇就能开玩啦！(・ω・)ノ

| 页面 | 内容 |
|---|---|
| 登录账户 | 微软正版账户 / 离线账户登录，多账户切换 |
| 创建实例 | 选版本、装加载器，创建你的第一个实例 |
| 安装内容 | 浏览 Modrinth / CurseForge，一键安装模组与整合包 |

**建议阅读顺序**：登录账户 → 创建实例 → 安装内容。三步走完，正式入坑~

更深入的玩法（实例管理、内容中心、实验室工具）见[游戏库与实例](../instance/what-is-instance.md))和[内容中心](../content/browse-search.md))章节。
