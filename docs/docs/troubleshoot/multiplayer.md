# 联机与正版验证问题

联机问题看着杂，其实就几层：客户端 → 网络 → 服务器 → 验证。一层层往下排。

## 提示 `invalid session` 或 `Failed to verify username`

服务器开了正版验证（`online-mode=true`），而你的账户不是正版，或者登录态过期了。

- 用离线账户进不去这类服务器，这是服务器规则，不是启动器的问题；
- 正版账户报这个，先退出账号重新登录一次，让启动器刷新登录态；
- 服务器列表里地址后面带端口（如 `play.xxx.com:25566`），端口错也会连到别的服务器。

## 朋友连不上我自己开的服

按顺序检查：

1. **单人游戏 → 对局域网开放**，记下聊天栏里的 `xxx.xxx.x.x:端口`；
2. 同一个 WiFi 下的朋友用内网 IP 能进，说明服务端没问题；
3. 外网要进，得做端口映射或内网穿透（路由器开端口、或用 frp 这类工具）；
4. Windows 防火墙第一次会弹「允许访问网络」，勾上**专用网络**，顺手把 `java.exe` / `javaw.exe` 放行；
5. 服务器 `server.properties` 里 `online-mode` 决定要不要正版，改成 `false` 才能让离线账户进（有安全风险，公网服别关）。

## 能进但一直「正在连接」/ 超时

- 服务器地址别带 `http://`、别带空格；
- 公网穿透免费线路会掉速、断连，换线路再试；
- 服务器端 `max-players` 已满会排队或被踢；
- 版本不一致会显示 `Incompatible version`，不是超时，注意区分提示文字。

## 进去之后人物不动、方块不加载

典型的丢包 / 延迟。先看服务器里的 `ping` 数值，再确认自己没开加速器 + 代理叠了两层。移动网络、校园网这类环境掉包很常见。

## 开了正版验证，但服务器是自建的

自建服想让正版玩家进、又不想让离线账户混进来，就保持 `online-mode=true`；反过来，纯朋友局可以直接关掉。两种模式不能同时满足，这是 Mojang 验证机制决定的。

## 联机时对方看不到我的皮肤

皮肤是客户端侧在 Mojang 服务器拉取的，离线账户没有皮肤记录，对方看到的就是默认皮肤。这与启动器无关。
