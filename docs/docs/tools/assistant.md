# AI 助手

玩家懒得翻文档很正常。这个页面把「问问题」和「翻文档」合成一件事：描述问题，助手先在本站文档里检索原文，再基于原文作答，并把出处放在回答下面，点一下就跳到对应小节。

<div id="cl-ai-embed"></div>

## 它能做什么

- **查文档**：问题会先过一遍全站文档索引（约 180 个正文小节），命中原文才回答，减少瞎编。
- **给出处**：每个回答下面挂「文档」按钮，点开直达原文位置。
- **认截图**：报错窗口、启动器界面、日志片段都能直接发图，它按图里能看到的内容判断。
- **不装懂**：文档里确实没有的，会标出「本站文档没收录」，再给外部检索结果，不会硬编一条路径给你。

## 说明

- 助手由服务端代理调用模型，本页不接触任何模型密钥。
- 回答是模型生成的，按钮名、菜单位置仍以文档和客户端实际界面为准。
- 标着「网络」的来源不是本站文档，属于外部检索，只作参考。
- 单次请求限流 20 次 / 分钟，问太快会提示稍等。

## 想让文档多写点？

在 [GitHub 仓库](https://github.com/maoxinhe/ChronLink/issues) 提个 Issue，说清楚「什么情况下、看到什么现象、试过什么」，比只写一句「打不开」有用得多。
