# 什么是实例

**实例 (Instance)** 是 ChronLink 的核心概念，用大白话讲：

> 每个实例就是一间**独立的游戏房间**——房间里有自己的游戏版本、自己的模组、自己的存档。房间之间完全隔离，互不干扰。

## 为什么需要实例？

举个真实场景：

- 你平时玩**原版生存**，不想被模组打扰
- 朋友叫你玩一个**整合包服务器**，那个整合包要装 50 个模组
- 你想试试**光影**，但怕影响别的存档

如果没有实例，这些需求会挤在一起互相打架（模组冲突、版本不兼容……）。有了实例，每个需求一间房，各玩各的：

| 实例 | 版本 | 内容 | 用途 |
|---|---|---|---|
| 我的生存 | 1.21 原版 | 纯净 | 日常生存 |
| 开黑服 | 1.20.1 Fabric | 50 个模组 | 和朋友玩 |
| 光影体验 | 1.21 原版+光影 | 光影包 | 截图看风景 |

## 游戏库页面

**游戏库 (Library)** 就是所有实例的“总览大厅”，在这里：

- **概览**：看到所有实例，点一下就能启动
- **官方**：按版本创建的原版实例
- **整合包**：从整合包创建的实例
- **已下载**：安装过内容的汇总
- **服务器**：服务器快捷入口，见[多人游戏](../online/multiplayer.md))
- **自定义**：手动配置的实例

## 实例从哪来？

- **创建**：选版本/加载器新建（见[创建实例](create-instance.md))）
- **整合包**：一键安装现成整合包，自动生成实例
- **导入**：朋友发你一个 `.mrpack` 文件，拖进来就有同款实例

创建好之后，点进实例就能看到它的[详情页](instance-details.md))。
