# 浏览与搜索

## 内容类型：先知道自己在找什么

| 类型 | 大白话 | 新手建议 |
|---|---|---|
| **模组 (Mods)** | 给游戏加功能的小插件 | 想给游戏加东西就找它 |
| **整合包 (Modpacks)** | 别人配好的一大包模组 | 想省事直接玩全套体验，首选 |
| **资源包 (Resource Packs)** | 换游戏外观、音效 | 想让画面更好看可以试试 |
| **光影 (Shader Packs)** | 画质特效，非常吃配置 | 电脑配置一般的话先别碰 |

## 搜索

顶部搜索框输入关键词就能搜，比如：

- 想加小地图 → 搜 “小地图” 或 “minimap”
- 想玩科技模组 → 搜 “机械动力” 或 “create”
- 想玩空岛 → 搜 “空岛” 或 “skyblock”

搜索会同时显示 Modrinth 和 CurseForge 两个平台的结果。

## 筛选

搜索结果太多？用筛选器缩小范围：

- **平台**：只看 Modrinth 或只看 CurseForge
- **分类**：按类型筛
- **加载器**：只看 Fabric 或只看 Forge 的模组（**注意：加载器必须和你实例一致**）

## 排行榜和推荐

不知道装什么？浏览页有排行榜和精选推荐，看看大家都在玩什么，直接抄作业~（下载量高的通常更靠谱）
