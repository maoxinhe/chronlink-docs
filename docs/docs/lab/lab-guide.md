# 实验室功能详解

实验室是启动器内置的工具箱，7 个小工具全部本地运行，不用开浏览器：

| 工具 | 干什么 |
|---|---|
| **皮肤编辑器** | 本地创建和编辑玩家皮肤 |
| **渐变文字生成器** | 生成 Minecraft 渐变色文字代码 |
| **种子地图** | 输入种子查看群系、结构分布 |
| **投影工坊** | 预览、编辑 .litematic / .schem 投影文件 |
| **配方生成器** | 改合成表、自定义配方、生成数据包 |
| **命令生成器** | 可视化拼 Minecraft Java 版命令 |
| **旗帜设计师** | 用全部 Java 版图案与染料设计旗帜 |

## 种子地图

输入地图种子，本地直接渲染群系分布和结构位置，找村庄、找要塞、找丛林神庙不用反复试种子：

选好 Minecraft 版本和维度（主世界 / 下界 / 末地），输入种子即可浏览，支持标记保存。

## 投影工坊

把投影文件拖进来即可 3D 预览，看层数、方块清单，找基友的建筑方案先在这里“云监工”：

也支持简单编辑，改完导出。
