# 游戏库与实例

实例 是 ChronLink 里最重要的概念，理解它很简单：

Updated Aug 13, 2026

This page has no translation yet; the Chinese original is shown.

**实例**是 ChronLink 里最重要的概念，理解它很简单：

> 每个实例 = 一间独立的“游戏房间”：自己的游戏版本、自己的模组、自己的存档、自己的设置。

就像你有两间房：一间住人，一间放杂物。互不打扰，想住哪间住哪间。

## 新手建议

- 刚入门：**一个实例就够了**（原版，先玩起来）
- 玩腻了：再建一个**模组实例**（带 Fabric，装模组玩）
- 朋友拉你开黑：给那个服务器单独建个实例，装它需要的模组
