# 实验室

实验室（Lab）是 ChronLink 内置的实用工具箱。

Updated Aug 13, 2026

This page has no translation yet; the Chinese original is shown.

**实验室 (Lab)** 是 ChronLink 内置的实用工具箱。

> 给新手的话：这些是**进阶工具**，先把游戏玩起来，等有需求了再来翻——它们不会跑。

## 工具一览

| 工具 | 用途 | 目标对象 |
| --- | --- | --- |
| [种子地图](../../../docs/lab/seed-map.md)) | 输入种子，然后查找结构与群系 | 想找好出生点的生存玩家 |
| [投影预览](../../../docs/lab/projection-preview.md)) | 预览投影文件，进行简单编辑 | 建筑，红石玩家 |
| [配方生成器](../../../docs/lab/recipe-generator.md)) | 设计自定义合成配方 | 整合包作者 |
| [渐变文字](../../../docs/online/gradient-text.md)) | 生成彩色文字 | 想在游戏里发彩色文字的玩家 |
| [模组翻译](../../../docs/content/mod-translation.md)) | 汉化没翻译的模组 | 汉化组、想玩未汉化模组的玩家 |

从启动器侧边栏即可进入实验室。
