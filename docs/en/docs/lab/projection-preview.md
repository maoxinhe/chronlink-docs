# 投影预览

投影文件 是建筑图纸——别人精心设计的建筑，会保存成 .schem / .schematic 文件分享。

Updated Aug 13, 2026

This page has no translation yet; the Chinese original is shown.

**投影文件**是建筑图纸——别人精心设计的建筑，会保存成 `.schem` / `.schematic` 文件分享。

**投影预览**让你**不进入游戏**，直接预览这个建筑成品长什么样。

## 能干什么？

- 看建筑成品效果（正面、结构一目了然）
- 看每个方块的位置和构成
- 了解建筑的大小尺寸

## 谁用得上？

- **建筑党**：下大佬的建筑图纸前，先预览效果，好看再装进游戏
- **学习党**：研究大佬建筑的方块布局，偷师学艺
- **规划党**：在图纸上研究改造方案，进游戏不返工

## 怎么用

实验室 → 投影预览 → 加载投影文件（`.schem` / `.schematic`）。

配合 [种子地图](../../../docs/lab/seed-map.md))规划基地、用 [配方生成器](../../../docs/lab/recipe-generator.md))定制玩法，建筑工作流一条龙\~

> 新手提示：这个工具等你想认真搞建筑时再研究也不迟。
