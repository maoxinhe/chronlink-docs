实例管理

实例库

侧边栏点 实例库，所有实例都在这里：

  • 顶部标签：全部实例 / 整合包 / 服务器 / 自定义，按来源分类

实例库：左上角可切换排序、分组和列表 / 网格视图 · 点图可看大图

  • 搜索框支持按名称查找；右侧可以按名称排序、按分组归类
  • 新建分组：给实例归类（比如“生存”“模组”“服务器包”），分组显示在侧边栏
  • 鼠标悬停实例卡片可以查看详情、右键有更多操作

实例详情五大标签

点进任意实例，顶部有五个标签页：

内容

管理模组、资源包、光影包：

  • 每个模组一行：右侧开关 = 启用/禁用，🗑 = 删除，⬇ = 有更新时一键更新
  • 可更新 33：勾选全部可更新项后点右下角下载图标批量更新
  • 浏览内容：跳到发现内容页，直接给这个实例找模组
  • 查看依赖关系：看模组之间的前置依赖
  • 旧文件与备份：整理重复文件和历史备份
  • 整合包实例顶部会有「解除整合包关联」，解除后就可以自由增删模组（注意：之后不再跟随整合包更新）

文件

内置文件浏览器，直接管理实例目录（config、saves、mods……），还有个「打开 Studio」测试版编辑器：

截图

这个实例的游戏截图。

世界

存档管理：进世界、备份、删除，点「编辑存档」可以改游戏模式、时间、天气等（详情见下文世界编辑）。

日志

带颜色的实时日志，支持搜索和按级别过滤（错误 / 警告 / 信息），游戏崩溃后这里就是第一现场，右上角「分享」可以直接生成日志分享链接：

实例设置

点实例页右上角的 齿轮图标，打开实例设置：

分类能干什么
通用改名称、图标、复制实例、创建桌面快捷方式、游戏目录、更新渠道
安装更换 / 升级加载器和游戏版本（比如 Forge 1.20.1 → NeoForge）
同步实例同步相关
备份创建备份、还原备份、备份库
核心组件管理实例里的核心组件
游戏窗口窗口标题、分辨率、全屏等
Java 及内存单独指定这个实例用哪个 Java、分配多少内存（FAQ：内存不够卡顿优先来这里调）
启动准备启动前执行的命令、环境变量

给单个实例改 Java 和内存：实例设置 → Java 及内存。想改所有实例的默认值去 设置 → 默认实例选项。

升级整合包 / 游戏版本

整合包出新版本、或者想把实例从 1.20.1 升到 1.21，不用重建：

  1. 在实例的「安装」分类或整合包详情页触发升级流程
  2. 启动器会自动分析：哪些模组能保留、哪些要换版本、哪些依赖冲突
  3. 按向导走 选择 → 兼容性 → 确认 → 进度 → 结果，全程可回退

升级过程启动器会自动备份，翻车了可以从备份还原。

拖放导入

直接把文件拖进启动器窗口：

拖入什么会发生什么
.mrpack / .zip 整合包创建整合包实例
.jar / .litemod 模组装进当前选中的实例
.litematic / .schem 投影打开投影工坊预览
.xmx / 世界文件夹导入世界
整个 .minecraft 文件夹导入为实例

全局世界与截图

侧边栏的 世界 和 截图中心 是跨实例的全局页面：

  • 截图中心按日期归档所有实例的截图，可搜索、新建分组、编辑、复制路径：
  • 世界页面会汇总各实例的存档（需要开启对应开关）
